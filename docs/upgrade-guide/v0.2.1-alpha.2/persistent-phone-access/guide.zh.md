# 持久完整手机访问

[English](guide.md) | 中文

## 变更

配对弹窗不再选择单个 Session，而是明确授权此实例的完整 Web 客户端，包括设置、文件、终端和审批。会话执行权限不变。设备信任跨 Host 和中继重启保留，一次性配对票据仍会过期。关闭弹窗不会断开手机，已配对状态移除二维码。

中继不再提供独立文本界面或 `/app.js`。旧文本授权需要重新配对完整版，但升级不会删除浏览器记录。现有消费者仍可使用协议 1。连接状态在实际 Web 应用挂载前保持加载中；启动失败可重新加载且不清除设备信任。

## 迁移

1. 升级中继以支持 `POST /desktop/devices`、协议 2、`full-client-e2ee` 和受保护的持久存储。升级时保留该存储；旧的内存中继无法恢复设备信任。
2. 重建并重启原有 DSH 入口。保留 `mobile-controller.config.enabled`、`relayOrigin` 和独立的 `DSH_MOBILE_DESKTOP_TOKEN`；不要暴露中继管理员凭据。
3. 手机用户需要选择 Host 目录时，组合现有 browse 目录选择后端和界面。原生 Electron 集成仍仅限桌面使用。
4. 从旧文本授权升级时，打开手机远控，确认整实例访问并重新配对。已有整实例设备在保留中继存储和浏览器数据时继续保留信任。
5. 确认二维码消失、完整 Web 客户端加载，并在刷新和 Host 重启后保留访问。使用忘记设备撤销；服务器撤销未确认时重试。浏览器数据被清除或淘汰后需重新配对。
